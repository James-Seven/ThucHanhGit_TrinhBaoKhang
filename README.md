# THỰC HÀNH GIT VÀ GITHUB

## 1. Giới thiệu
Repository thực hành các thao tác quản lý phiên bản
bằng Git và GitHub trên hệ điều hành Ubuntu.

## 2. Các nội dung đã thực hiện
- Khởi tạo và quản lý Git repository.
- Thực hiện add, commit, log, status.
- Tạo nhánh, chuyển nhánh và merge.
- Giải quyết xung đột và sử dụng rebase.
- Kết nối và đồng bộ với GitHub.
- Thực hành clone, push, pull, fetch.
- Khôi phục dữ liệu bằng restore, revert, reflog.
- Tìm commit gây lỗi bằng git bisect.
- Sử dụng git grep, stash và alias.
- Quản lý Git submodule.

## 3. Cách sử dụng
Clone repository:

git clone https://github.com/James-Seven/ThucHanhGit_TrinhBaoKhang.git

Truy cập thư mục:

cd ThucHanhGit_TrinhBaoKhang

Kiểm tra trạng thái:

git status

Xem lịch sử commit:

git log --oneline

## 4. Công cụ sử dụng
- Ubuntu (VMware Workstation)
- Git
- GitHub
- Terminal
